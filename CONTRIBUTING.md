# Contributing

Issues and pull requests are welcome.

- Run the checks before opening a PR: `node tests/test_i18n.js`, `node tests/test_modules.js`, `node tests/test_pin.js`, `python3 -m unittest discover tests`.
- Every user-visible string goes through `app/i18n.js` in Romanian, English and Spanish (the parity test enforces it).
- Placement code must keep the plan, write, verify, roll back sequence.
- Use only audio you own or that is redistributable; do not attach private sound libraries to issues.
- Commits carry real authorship only.
